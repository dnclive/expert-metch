# ООО «ЭКСПЕРТ» — сайт о мерчандайзинге

Одностраничный статический сайт компании ООО «ЭКСПЕРТ» (мерчандайзинг, промо-мероприятия, аудит торговых точек).
Без сборки, без форм, без скриптов, без аналитики и cookies.

## Файлы

- `index.html` — вся страница; стили встроены в `<style>`.
- `404.html` — страница «не найдено».
- `favicon.svg`, `favicon-32.png` — значок сайта.
- `og.png` — картинка для превью ссылок (1200×630), снята со `source/og.html`.
- `robots.txt`, `sitemap.xml` — для поисковиков.
- `CNAME` — домен сайта для GitHub Pages: `merch.expertcom777.com`.
- `source/chatium-2026-10-22.md` — исходные тексты прежней страницы, откуда взято каждое утверждение.

## Как править

Тексты и контакты меняются прямо в `index.html` любым редактором; проверить — открыть файл в браузере.
Если меняется заголовок или цифры — обновить `source/og.html` и пересобрать `og.png` снимком 1200×630.

## Публикация (GitHub Pages)

Адрес сайта: https://merch.expertcom777.com/

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Каждый push в `main`
публикуется сам, через минуту-две. Домен задаёт файл `CNAME` (одна строка: `merch.expertcom777.com`); в DNS — запись CNAME
`merch` на `<владелец>.github.io`, без проксирования. В Settings → Pages включена «Enforce HTTPS».

Сайт живёт в корне домена: ссылки в `index.html` относительные, в `404.html` — от корня (`/`), чтобы
страница «не найдено» работала на любом пути. По адресу `<владелец>.github.io/<репозиторий>/` Pages
перенаправляет на домен.

Если домен сменится — поменять его в `CNAME`, `index.html` (canonical, og:url, og:image), `robots.txt`,
`sitemap.xml` и в этом файле.
